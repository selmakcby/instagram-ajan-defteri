# Token kayıt promptu

Meta'dan aldığın token'ı sohbete yapıştırma. Panoya kopyala, sonra:

```
Meta'dan Instagram token'ını aldım, panoya kopyaladım.
Bunu projenin .env dosyasına IG_TOKEN olarak kaydet.
Değeri ekrana basma, loga yazma; sonra panoyu temizle.
.env dosyası git'e girmesin.
```

Aynı kalıp her anahtar için geçerli (Telegram bot token'ı, tablo anahtarı vb.).
